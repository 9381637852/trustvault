# 🔒 TrustVault - Secure Document Sharing & Audit Trail

A secure, enterprise-ready document sharing platform built with granular access control and a tamper-evident audit trail for every document interaction.

## 📌 Problem Statement
In modern workplaces, sensitive business documents (contracts, financial reports, HR records) are frequently shared via insecure channels without access tracking. 

**TrustVault** solves this by providing:
1. **Confidentiality:** Documents can be protected with access keys and time-based auto-expiration.
2. **Auditability:** Complete, immutable audit log of who uploaded, accessed, downloaded, or shared each document.
3. **Governance:** Instant access revocation and real-time monitoring.

---

## ✨ Key Features

- 📁 **Secure Document Upload & Management:** Upload sensitive documents with metadata and file integrity checks.
- 🔑 **Access Control & Permissions:** Set view-only or download permissions, passcodes, and document expiry dates.
- 📜 **Comprehensive Audit Trail:** Real-time logging of user events:
  - Document Uploaded
  - Document Viewed / Opened
  - Document Downloaded
  - Permissions Modified / Access Revoked
  - Timestamp and user action logs
- ⚡ **Real-time Activity Dashboard:** Quick visibility into document views, download counts, and recent security logs.
- 📱 **Responsive & Modern UI:** Clean, intuitive interface optimized for desktop and mobile devices.
